# Plan

Use the CLI Report and Action Queue as the factual basis. Explain what must change, why it affects the declared release, where to investigate, and what Evidence must be recollected.

Provider options are advisory. State the capability requirement first, then use confirmed budget, scale, region, stack, operational tolerance, and lock-in preferences. Never treat a recommendation as Machine Evidence or authority to provision resources.

The initial scaffold reserves `rally plan` but does not implement Plan generation.
